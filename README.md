# FitLog

A dark, modern workout library and workout planning application.

## Live Demo

[FITLOG](https://fitlog-alpha-six.vercel.app/)

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- LocalStorage
- REST API

## Features

- Browse workout library
- View workout details
- Create today's workout plan
- Save workouts for later
- Track completed workouts
- Responsive design
- Workout sorting
- Persistent localStorage data
